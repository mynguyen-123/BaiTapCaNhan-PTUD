4. Nội dung các bài Lab
Lab 08 – JavaScript 1: Language Foundations
Tìm hiểu những kiến thức nền tảng của JavaScript, bao gồm biến, kiểu dữ liệu, các cấu trúc cơ bản và hàm. Bài thực hành cũng giúp sinh viên làm việc với String, Date, Array và Object, đồng thời làm quen với Browser Console để kiểm tra mã nguồn.
Lab 09 – JavaScript 2: DOM and Events
Thực hành truy xuất và thao tác với các phần tử HTML thông qua DOM. Nội dung gồm đọc và thay đổi nội dung, thuộc tính, kiểu hiển thị của phần tử; thêm và xóa phần tử HTML; xử lý sự kiện như click, mouseover, mouseout và làm việc với Form để kiểm tra dữ liệu đầu vào.
Lab 10 – JavaScript 3: jQuery
Làm quen với thư viện jQuery và cách sử dụng Selectors để truy xuất phần tử HTML. Bài thực hành tập trung vào xử lý sự kiện, thao tác DOM, tạo hiệu ứng và hoạt ảnh, thực hiện GET Requests cũng như xử lý dữ liệu trả về.
